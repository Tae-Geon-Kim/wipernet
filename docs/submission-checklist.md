## 3. 접수 메일

- 받는 곳: `appdevchallenge@hyundai-partners.com`
- 제목: `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`
- 본문: 저장소 주소, 최종 커밋 번호, 영상 링크(있으면)
- 첨부: 접수양식(기획서), 서명한 동의서, 추가 자료
- 고쳐서 다시 낼 때: **처음 보낸 메일 주소로**, 제목 앞에 `[수정제출]`, 전체 자료와 서명한 동의서를 모두 다시 첨부한다. 마감 전 마지막 제출본으로 심사한다.

```bash
git log --format='%an %ae' | sort -u
git grep -n -i -e '<실명>' -e '<개인 이메일 아이디>'
```

- 운영사무국 답변(2026-11-12): GitHub 신원정보 익명화는 요구하지 않고, 실명이 드러나는 개인 계정 저장소를 제출해도 감점·실격이 없다. 그래서 APK 파일 이름에 실명을 쓴다(사용자 결정).

## 5. 공지에서 확인한 운영 규칙

- 공개된 Pleos SDK(Vehicle, NaviHelper, TTS, STT, FusedLocation)만 쓴다. "준비 중" 표시여도 문서 방법대로 에뮬레이터에서 쓸 수 있다.
- 차량 마이크 음성을 외부 음성 인식 서비스로 보내지 않는다(와이퍼넷은 Pleos STT만 쓴다).
- 2차 PT는 에뮬레이터에서 구동되는 앱 시연이다. 실차는 필요 없다.
- 운영사무국은 운영 문의에만 답하고, 구현 방법이나 API 동작 문의에는 답하지 않는다.
