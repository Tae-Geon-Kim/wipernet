# 시연 영상 대본과 촬영 목록

설계 5.5 흐름(6장면)을 실제 화면에 맞췄다. 목표 길이 1분 30초~2분. 녹화와 편집은 사용자가 하고, 장면마다 화면을 띄우는 명령을 아래에 적는다. 앱 데모는 1배속으로 처음부터 끝까지 약 9.5분이라, 장면 4~6은 필요한 순간만 잘라 쓴다.

자막의 숫자는 [`validation.md`](validation.md)에서 가져왔다. 18:17 서울 전역 재난문자와 21:00께 개포 통제는 보도 기준이다(통제 출처는 `shared/underpasses_gangnam.md`). 18:17 문자는 자막에 넣기 전에 보도 링크를 한 번 더 확인한다.

## 촬영 준비

```bash
# 에뮬레이터 (M1 맥 기준, docs/setup-status.md)
~/Library/Android/sdk/emulator/emulator -avd Pleos_Connect_v2.1.0 -no-snapshot-load -gpu host -feature -Vulkan
adb forward tcp:8088 tcp:8088          # Virtual Console: http://127.0.0.1:8088/ 를 브라우저에 열어 둔다
adb install -r apk/김태건_WiperNet_release.apk        # 처음 한 번. 동의, 알림·마이크 허용
```

## 장면 2·3: 뷰어

```bash
cd backend
.venv/bin/uvicorn wipernet_server.api:app --port 8000          # 창 1
# 창 2: 현재 밀도. 17:20부터 60배속이면 18:10까지 약 50초
.venv/bin/python -m wipernet_sim.runner --density current --speed 60 --from 17:20 --to 18:10
# 끝나면 서버를 다시 켜고(메모리 초기화) 미래 밀도로 같은 구간
.venv/bin/python -m wipernet_sim.runner --density future --speed 60 --from 17:20 --to 18:10
```

브라우저에서 http://127.0.0.1:8000/viewer 를 열고 화면 녹화한다. 미래 밀도는 약 40배속까지만 따라가므로 녹화가 조금 더 길다(기능지도 8장).

## 장면 4~6: 앱 데모

1. Virtual Console에서 창문을 조금 열고, 디프로스터와 전조등을 끈다(준비 동작이 화면에 보이게).
2. 와이퍼넷을 열고 **데모 처음부터**를 누른 뒤 녹화를 시작한다.
3. 약 30초: 차량 준비 음성과 Virtual Console 변화(장면 4).
4. 약 210초: 경고 띠와 음성, 우회 질문(장면 5). 질문이 끝나면 알림 창을 내리고 **예**를 누른다(창이 다 펼쳐진 뒤에 누른다).
5. 비 지도(장면 6): 도착은 약 9.5분 뒤다. 녹화를 이어 두고 편집에서 자르거나, 데모를 따로 끝까지 돌려 기어 P가 된 뒤 **비 지도**를 눌러 찍는다.

경고 순간에 앱 화면이 앞에 있어야 경고 띠가 보인다. "뒤에서도 동작"을 보여 주려면 같은 장면을 내비를 띄운 채 한 번 더 찍는다(알림 창에 경고가 들어온다).
