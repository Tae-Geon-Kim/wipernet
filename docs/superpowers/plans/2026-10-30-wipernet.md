# 와이퍼넷(WiperNet) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 와이퍼 데이터를 모으는 서버, 가상 차량 수백 대로 2022-08-08 강남 폭우를 재현하는 시뮬레이터, 지하차도 침수 경고·우회·차량 준비를 하는 Pleos 차량 앱을 만들고, 1차 제출용 데모 영상·GitHub·APK까지 낸다.

**Architecture:** 하나의 저장소에 `backend/`(Python: 서버 `wipernet_server` + 시뮬레이터 `wipernet_sim`)와 `car-app/`(Kotlin Android)을 둔다. 시뮬레이터와 차량 앱은 **같은 서버 API**에 원시 와이퍼 이벤트(스위치·상태)를 보내고, 세기 추정(AUTO 포함)·격자 집계·지하차도 위험 계산·외부 자료(기상특보, 재난문자, 레이더)와의 교차 확인은 서버 한 곳에서만 한다. 모든 시간 계산은 이벤트 시각(시뮬레이션 시각) 기준이라 압축 재생이 된다. 외부 자료도 "실시간 / 기록 재생" 두 가지로 두어 2022-08-08 재현에 맞춘다(설계 6.10).

**Tech Stack:** Python 3.12+, FastAPI, uvicorn, pydantic v2, httpx, pytest, osmnx/networkx(도로망 1회 추출), Leaflet 1.9.4(뷰어), 공공 API(기상청 기상특보·레이더, 행정안전부 긴급재난문자) · Kotlin, Android Gradle Plugin(Gradle 8+), minSdk 28, Jetpack Compose, kotlinx.coroutines, OkHttp, kotlinx.serialization, JUnit4 · Pleos Connect SDK(Vehicle 읽기·제어, NaviHelper, FusedLocation, TTS, STT. 제어는 Virtual Console이 열려 있을 때만 반영된다, 2026-11-10) · Pleos Connect Emulator v2.1.0+ 와 Virtual Console.

**Spec:** `docs/2026-10-30-wipernet-design.md`

## Global Constraints

- 마감: 2026-11-15 23:59 이메일 제출. 범위는 줄이지 않는다. 일정이 밀리면 빼지 말고 사용자에게 먼저 알린다.
