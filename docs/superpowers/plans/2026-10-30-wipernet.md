# 와이퍼넷(WiperNet) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 와이퍼 데이터를 모으는 서버, 가상 차량 수백 대로 2022-08-08 강남 폭우를 재현하는 시뮬레이터, 지하차도 침수 경고·우회·차량 준비를 하는 Pleos 차량 앱을 만들고, 1차 제출용 데모 영상·GitHub·APK까지 낸다.

**Architecture:** 하나의 저장소에 `backend/`(Python: 서버 `wipernet_server` + 시뮬레이터 `wipernet_sim`)와 `car-app/`(Kotlin Android)을 둔다. 시뮬레이터와 차량 앱은 **같은 서버 API**에 원시 와이퍼 이벤트(스위치·상태)를 보내고, 세기 추정(AUTO 포함)·격자 집계·지하차도 위험 계산은 서버 한 곳에서만 한다. 모든 시간 계산은 이벤트 시각(시뮬레이션 시각) 기준이라 압축 재생이 된다.

**Tech Stack:** Python 3.12+, FastAPI, uvicorn, pydantic v2, httpx, pytest, osmnx/networkx(도로망 1회 추출), Leaflet 1.9.4(뷰어) · Kotlin, Android Gradle Plugin(Gradle 8+), minSdk 28, Jetpack Compose, kotlinx.coroutines, OkHttp, kotlinx.serialization, JUnit4 · Pleos Connect SDK(Vehicle, NaviHelper, 가능하면 FusedLocation/TTS/STT/Vehicle Control) · Pleos Connect Emulator v2.1.0+ 와 Virtual Console.

**Spec:** `docs/2026-10-30-wipernet-design.md`
