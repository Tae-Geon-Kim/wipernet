# 와이퍼넷 (WiperNet)

> 도로 위 현대차들의 와이퍼 작동 정보를 익명으로 모아, 경로 앞 **지하차도 침수 위험을 미리 경고하고 우회를 권하며**, 비 구간에 들어가기 전에 **차를 미리 준비시키는** Pleos Connect 차량용 앱.

2026 현대자동차그룹 차량용 앱 개발 공모전 출품작입니다.

> [!NOTE]
> 개발 중입니다. 아래 표시 중 🚧는 아직 구현되지 않은 부분입니다. 기능별 진행 상태는 [기능지도](docs/FEATURES.md)에서 볼 수 있습니다.

서버 없이 APK만 설치해도 **데모 모드**로 2022-08-08 강남 폭우 시나리오가 처음부터 끝까지 재생됩니다.

| 항목 | 내용 |
|---|---|
| APK | 🚧 [GitHub Releases](../../releases)의 `와이퍼넷_release.apk` (저장소 [`release/`](release/) 폴더에도 같은 파일) |
| 테스트 환경 | Pleos Connect Emulator v2.1.0 이상, Android API 28 이상 |
| 필요한 설정 | 없음. 첫 실행 때 데이터 수집 동의 화면에서 "동의"를 누르면 데모 모드로 시작합니다 |

### 설치와 실행

```bash
adb install -r 와이퍼넷_release.apk
```

1. 에뮬레이터에서 와이퍼넷을 엽니다.
2. 동의 화면에서 **동의**를 누릅니다.
3. 데모가 시작됩니다. 약 3분 시점에 비 구간 진입 전 차량 준비(창문 닫기, 김서림 방지, 전조등) 음성이 나오고, 이어서 경로 앞 지하차도 침수 경고와 우회 질문이 나옵니다.
4. 기어를 P로 두면 비 지도 화면을 볼 수 있습니다.

## 해결하려는 문제

- 2023-07-15 오송 궁평2지하차도 침수로 14명이 숨졌습니다.
- 감사원 조사(2024)에서 전국 지하차도 1,086곳 중 182곳이 침수 우려가 크고, 132곳에는 진입 차단시설이 없었습니다.
- 진입 차단시설은 **이미 물이 찬 뒤** 작동합니다. 와이퍼넷은 그 전에, 운전자가 지하차도 쪽 경로를 고르기 전에 알려 줍니다.

한국 내수 시장에서 현대차그룹 차량 비중은 약 90%입니다. 와이퍼를 켠 차가 많을수록 비 지도가 촘촘해지고, 경고가 정확해집니다.

## 주요 기능

1. **지하차도 침수 경고 + 우회 권유**: 경로 앞 지하차도 주변에서 여러 차가 동시에 폭우를 감지하면 음성과 알림으로 알리고, 동의하면 내비 경로를 바꿉니다.
2. **비 구간 진입 전 차량 준비**: 창문 닫기, 김서림 방지, 전조등 켜기를 Pleos Vehicle SDK로 직접 제어합니다.
3. **비 지도**: 정차·주차 중에 경로 위 비 세기와 위험 지하차도를 보여 줍니다.

운전 중에는 음성과 한눈에 보이는 경고만 씁니다. 위험할 때도 앱 화면을 강제로 띄우지 않아 내비를 가리지 않습니다.

## 구조

```
┌────────────────────┐      같은 API      ┌──────────────────────┐
│ 가상 차량 시뮬레이터 │ ───────────────▶ │                      │
│ (수백 대, 2022-08-08 │   와이퍼 이벤트    │        서버          │
│  강남 폭우 재현)     │                   │  격자 비 지도 집계    │
└────────────────────┘                   │  지하차도 위험 단계   │
                                          │                      │
┌────────────────────┐  와이퍼 이벤트 ──▶ │                      │
│ 차량 앱 (에뮬레이터) │ ◀── 위험 정보 ─── │                      │
│ 경고 · 우회 · 준비  │                   └──────────────────────┘
└────────────────────┘
```

- 시뮬레이터와 차량 앱은 **같은 서버 API**로 데이터를 보냅니다. 서버 입장에서는 가상 차와 실제 차가 구분되지 않습니다.
- 세기 추정, 격자 집계, 위험 판단은 서버 한 곳에서만 합니다.
- 차량 ID는 15분마다 바뀌는 임시 ID이고, 서버는 원시 이벤트를 2시간까지만 보관합니다. 개인 이동 경로는 저장하지 않습니다.

| 폴더 | 내용 | 기술 |
|---|---|---|
| `backend/wipernet_server` | 서버 | Python 3.12, FastAPI |
| `backend/wipernet_sim` | 가상 차량 시뮬레이터, 검증 | Python, osmnx |
| `car-app/` | Pleos 차량 앱 | Kotlin, Jetpack Compose, Pleos Connect SDK |
| `docs/` | 설계, API 계약, [기능지도](docs/FEATURES.md) | |

사용하는 Pleos SDK: Vehicle(와이퍼·창문·공조·조명), NaviHelper(경로·지하차도 안내), FusedLocation(위치), TextToSpeech(음성 안내).

## 전체 시스템 실행 (개발자용) 🚧

라이브 모드는 서버, 시뮬레이터, 에뮬레이터를 한 Mac에서 함께 돌립니다.

### 1. 서버

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/uvicorn wipernet_server.api:app --port 8000
```

### 2. 시뮬레이터와 뷰어

```bash
cd backend
.venv/bin/python -m wipernet_sim.runner --density future --speed 60
```

브라우저에서 http://127.0.0.1:8000/viewer 를 열면 가상 차량, 비 지도, 지하차도 위험 단계가 실시간으로 보입니다.

### 3. 차량 앱

```bash
cd car-app
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

앱 설정에서 모드를 **라이브**로 바꾸면 서버(`http://10.0.2.2:8000`)에 연결합니다. Virtual Console(`adb forward tcp:8088 tcp:8088` 뒤 http://127.0.0.1:8088/)에서 와이퍼를 바꾸면 뷰어에 내 차가 나타납니다.

### 테스트

```bash
cd backend && .venv/bin/pytest -v
cd car-app && ./gradlew test
```

## 검증 🚧

- **재현 검증**: 잡음 섞인 와이퍼 신호만으로 시뮬레이터의 실제 강우장을 얼마나 복원하는지(오차, 비 감지 적중률, 오경보율)를 차량 밀도 두 가지로 비교합니다.
- **현실성 검증**: 기상청 AWS 관측소의 70%로만 강우장을 만들고, 숨긴 30%의 실제 관측값과 비교합니다.

결과는 `docs/validation.md`에 정리합니다.

## 한계와 가정

- 실차에서 검증하지 않았습니다. 모든 시연은 Pleos Connect Emulator에서 합니다.
- 와이퍼 AUTO 모드에서는 세기를 알 수 없어, 와이퍼 켜짐·꺼짐 전환 빈도로 추정합니다.
- 차량 밀도(현재 100대, 미래 1,500대)는 가정치입니다.
- 공모전 시연용 서버는 메모리에만 데이터를 둡니다. 실제 운영에서는 DB와 서버 호스팅이 필요합니다.
- 실제 App Market 배포에는 Vehicle SDK 권한 협의와 위치기반서비스사업 신고가 필요합니다.
